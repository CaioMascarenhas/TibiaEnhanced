# Tibia Enhanced 0.1.0 Beta 1

Versão beta para Windows x64. Recursos e compatibilidade ainda estão em validação.

## Recursos

- Recortes da janela do Tibia em espelhos flutuantes, com opacidade, ajuste de proporção e bloqueio de cliques.
- Alertas sonoros com timers personalizados, Foods, Potions, loops e controle de volume.
- Loot Split, EXP Share e cidade do Rashid considerando o server save.
- Perfis locais, temas claro e escuro e opção de minimizar para a bandeja.

## Download

- **Instalador:** `TibiaEnhanced-0.1.0-beta.1-windows-x64-setup.exe`.
- **Portátil:** `TibiaEnhanced-0.1.0-beta.1-windows-x64-portable.zip`. Extraia tudo e mantenha `_internal` ao lado de `TibiaEnhanced.exe`.

Não é necessário instalar Python. Os arquivos **Source code** contêm o código-fonte, não o aplicativo pronto.

## Atualizações e limitações

Atualizações são manuais: feche o aplicativo e execute o novo instalador na mesma pasta,
ou extraia o novo ZIP portátil em uma pasta separada. Os perfis são salvos fora da pasta do app.

A validação em máquina limpa sem Python, Windows 11, cliente Tibia real, diferentes escalas
e múltiplos monitores ainda precisa ser concluída. Consulte `docs/windows-build.md` para as evidências.

O projeto é independente e não é afiliado nem aprovado pela CipSoft. Os timers são iniciados
pelo jogador; o aplicativo não executa ações do jogo automaticamente.

Para reportar problemas, informe a versão do aplicativo, a versão do Windows e os passos para reprodução.
