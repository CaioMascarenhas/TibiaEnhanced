# Criar temporizadores com alertas de áudio personalizados

## Objetivo

Permitir que o jogador configure avisos por tempo e os controle manualmente.

## Critérios de aceite

- Cada alerta tem nome, duração, arquivo `.wav` ou `.mp3` e volume.
- Há controles para iniciar, pausar, retomar e reiniciar, com contagem regressiva visível.
- O som é reproduzido uma vez ao terminar; há botão para testá-lo.
- Vários temporizadores podem funcionar ao mesmo tempo.
- A contagem usa relógio monotônico e define o comportamento após suspensão do Windows.
- Atalhos, se incluídos nesta issue, atuam somente no aplicativo e têm conflitos detectados.
