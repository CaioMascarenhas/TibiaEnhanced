# Estruturar aplicativo desktop em Python e PySide6

## Objetivo

Criar a base executável do aplicativo com uma janela de controle e módulos separados para captura, espelhos, alertas e configurações.

## Critérios de aceite

- O projeto abre uma janela com seções **Recortes** e **Alertas**.
- Há comandos para mostrar, ocultar e encerrar o aplicativo pela bandeja do sistema.
- A interface permanece responsiva durante tarefas de captura.
- README contém instruções para instalar dependências e executar localmente.
- A estrutura separa interface, serviços e modelos, sem scripts independentes para o usuário iniciar.

## Dependências

Nenhuma. Primeira issue da implementação.
