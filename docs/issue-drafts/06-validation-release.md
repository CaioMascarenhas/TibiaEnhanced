# Validar no Windows e preparar distribuição

## Objetivo

Testar a primeira versão no ambiente real e gerar um pacote instalável.

## Critérios de aceite

- Testes manuais documentados cobrem captura, áudio, suspensão, DPI e vários monitores.
- O aplicativo informa quando a janela do Tibia desaparece e recupera a captura quando apropriado.
- Há instruções de instalação, execução e desinstalação.
- A distribuição não inclui segredos nem envia imagens ou dados do jogo para servidores.
- As regras atuais da CipSoft são revisadas antes da publicação, sem alegar aprovação oficial.

## Dependências

Issues 01 a 05.
