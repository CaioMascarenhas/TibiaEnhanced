# Salvar recortes, alertas e perfis localmente

## Objetivo

Restaurar a configuração do usuário entre sessões.

## Critérios de aceite

- Recortes, posições, nomes e preferências são salvos e restaurados.
- Alertas mantêm nome, duração, caminho do som e volume; temporizadores não iniciam sozinhos após reiniciar o aplicativo.
- Configurações inválidas ou arquivos de áudio ausentes geram aviso recuperável.
- O formato inclui versão de esquema para futuras migrações.
- O usuário pode criar e alternar perfis locais.

## Dependências

Issues 03 e 04.
